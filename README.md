# Дрон-камикадзе

FPV-дрон для Minecraft: крафтишь, ставишь на землю, задаёшь координаты — летит и детонирует.

## Как играть

1. Скрафтить дрон по рецепту
2. Правый клик по земле — дрон встаёт и висит неподвижно
3. Правый клик по дрону — открывается пульт
4. «Задать координаты» — написать в чат `X Y Z`
5. Дрон летит 8 блоков/сек и взрывается при попадании

Сбить можно стрелой — одно попадание, дрон падает без взрыва.

## Рецепт

Лежит в `config.yml`, меняется без пересборки:

```yaml
recipe:
  row1: "IRON_INGOT, REDSTONE_TORCH, IRON_INGOT"
  row2: "PHANTOM_MEMBRANE, TNT, PHANTOM_MEMBRANE"
  row3: "IRON_INGOT, REDSTONE_BLOCK, IRON_INGOT"
```

Пустая клетка — `AIR`. После правки: `/drone reload`.

## Команды

- `/drone give [ник] [кол-во]` — выдать дрон (нужен `drone.admin`)
- `/drone stop` — подорвать свои дроны в воздухе
- `/drone reload` — перечитать конфиг и рецепт

## Важно для сервера с друзьями

В `config.yml` по умолчанию `break-blocks: true` — взрыв ломает блоки, как ТНТ.
Если не хотите, чтобы сносило постройки:

```yaml
explosion:
  break-blocks: false
```

Тогда урон получат только существа, а мир останется цел.

## Защита от багов

- Дрон не горит на солнце (фантомы горят по умолчанию)
- Не атакует игроков, ИИ отключён
- Взрывается сам при разряде батареи или выходе за радиус
- Летящие дроны удаляются при выключении сервера, чтобы не зависали
- Стоящие дроны переживают рестарт и остаются управляемыми
- Предмет помечен внутренней меткой — подделать наковальней нельзя
